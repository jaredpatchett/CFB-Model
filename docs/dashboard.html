Built from CFBD (team data, SP+ ratings), The Odds API (moneyline/spread/total), and PrizePicks via OddsPapi (player props).

Model / EV column: since the 2026 season hasn't started, there's no in-season form yet for any team. The model line uses each team's most recent SP+ rating (a public power rating calibrated to approximate point spread) plus a home-field edge and uncertainty band both fit empirically from real 2021–2025 historical games. Games where either team is outside the FBS database (mostly FCS opponents) show "no line" rather than a fabricated number.

No model reliably beats a well-priced sportsbook line on every game. Treat this as research support, not a guarantee. Bet only what you're comfortable losing.
